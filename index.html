📘 Fundamentos de vectores

Un vector es una magnitud física que posee módulo, dirección y sentido.

1. Notación y componentes

$$\vec A = A_x\,\hat\imath + A_y\,\hat\jmath \quad\text{(2D)}\qquad \vec A = A_x\,\hat\imath + A_y\,\hat\jmath + A_z\,\hat k \quad\text{(3D)}$$

2. Magnitud

$$|\vec A| = \sqrt{A_x^2 + A_y^2}\qquad |\vec A| = \sqrt{A_x^2 + A_y^2 + A_z^2}$$

3. Ángulos directores

$$\cos\alpha = \frac{A_x}{|\vec A|},\quad \cos\beta = \frac{A_y}{|\vec A|},\quad \cos\gamma = \frac{A_z}{|\vec A|}$$

4. Producto escalar

$$\vec A\cdot\vec B = A_xB_x + A_yB_y + A_zB_z = |\vec A||\vec B|\cos\theta$$

5. Producto vectorial

$$\vec A\times\vec B = \begin{vmatrix}\hat\imath & \hat\jmath & \hat k\\ A_x & A_y & A_z\\ B_x & B_y & B_z\end{vmatrix}$$
